# Portail Decathlon CMA CGM Team

Cette archive contient la page d'accueil `index.html` et les documents fournis, renommés avec des noms simples pour que les liens fonctionnent sur GitHub Pages.

## Mise en ligne / remplacement

1. Décompresser cette archive.
2. Dans le dépôt GitHub `dct-portail`, ouvrir **Add file → Upload files**.
3. Déposer tous les fichiers présents dans ce dossier (y compris `index.html`) à la racine du dépôt.
4. Valider avec **Commit changes**. Accepter le remplacement des fichiers homonymes si GitHub le demande.
5. Garder GitHub Pages configuré sur `main` et `/ (root)`.

Les PDF individuels de Boris, Thierry, Tom et Efren ne sont pas inclus car ils n'étaient pas parmi les documents reçus.
